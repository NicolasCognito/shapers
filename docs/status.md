# What works / what doesn't yet / what the AI does

**What works:** My week (hours/quota, pro-rata behind indicator, streak, meetings and check-in), My tasks, Board grid/list with stars and open-task highlights, task ownership and handoffs accepted through Requests, older-hours approval with visible rejection reasons, admin cancellation/restoration of finished tasks, Team analytics and member history, server-enforced permissions, read-only Google Calendar sync every ten minutes, manual sandbox import, and English/Slovenian UI. **What doesn't yet:** full browser/mobile walkthrough and polish, Slack reminders and activity signals, badges/rankings beyond the existing streak, editable behind formula, automatic first-start import, return-to-pool workflow and new-request notifications. Temporary quick-login buttons still need removal; an upstream demo user is retained for migration tests. Voice input in the Jarvis chat works through browser speech recognition, and through server-side Whisper (Groq) once a key is configured; Jarvis meeting-tool routing still needs live confirmation. **What the AI does:** Jarvis uses configured DeepSeek chat and tools to summarise the member's week, log recent hours, request older hours, report attendance, help with Board/personal calendar actions and answer admin team questions. It replies in the user's language; server permissions restrict other members' data. Implemented features are based on code review and the project TODO, not a fresh end-to-end verification of the public deployment.
